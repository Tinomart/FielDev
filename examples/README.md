# Examples

Open one with **File → Open example file**, or run it without the application:
`python scripts/run_example.py examples/04_handles.py`. **Every example runs as it is** and makes its own geometry from
primitives, fields and points; the application switches to a script's folder when it opens it. Every one of them opens in under
two seconds, except `12` (mesh export and import), which writes a mesh and reads it back the first time it runs.

| Script | Part | Shows |
|---|---|---|
| `04_handles.py` | none (a small crate) | the gizmo (`gizmo()`: click / never / always), the handles on the surfaces (`handles()`), and the lock, of the model tree |
| `12_mesh_export_and_import.py` | none (a cup) | STL out with `save_stl` and back in with `import_model` |
| `18_fields_everywhere.py` | none | wherever a number goes, a field goes: a plate grown by a field (`offset`), a blend radius that varies (`smooth_union`), a smoothing radius that varies (`smooth`), driven from a `point` |
| `20_custom_blocks.py` | none | custom blocks (`blocks/sample_blocks.py`): `perforate` with a field radius, `bracket` |
| `21_low_level.py` | none | low-level fields, as in libfive's Scheme `define-shape` / `remap-shape`: a cube from six plane distances (`.max`), a twist by `.remap`, a ball and a torus from their formulas joined by a smooth minimum of your own, a gyroid cut to a cube; evaluating and printing a tree |
| `22_export_files.py` | none (a beam with a hole) | exporting: `export_mesh` in every format (STL, OBJ, PLY, 3MF, glTF, FBX, OFF, DXF); sections in the model tree |
| `26_profiles_and_sweeps.py` | none | points, a **profile** (corners and a spline point), `extrude`, a `spline` and `path_extrude` of a profile whose thickness follows the scale of a point: pull a point out of an edge, double-click a point, scale it with its ring |
| `27_copies_and_linked_copies.py` | none (a plate with lugs and bolts) | `Shift+D` (a copy) against `Ctrl+D` (a linked copy, `instance`): three bolts that follow the first one, a lug copied and changed on its own; shadows in the model tree |
| `28_profile_on_a_plane.py` | none | a profile in a tilted plane, `extrude` along the normal of its plane, a smooth badge on it, and how to draw on the plane with the **work plane** (`Shift+W`) |
| `29_symmetry.py` | none (a round table: a top, and one leg -- a profile swept along a spline) | a three-way **symmetry** (`symmetry_planes(kind='turn', copies=3)`: three turned copies, nothing mirrored -- any number up to 24, or planes): select it and everything you make is made at its images too; `symmetry_images(leg, mirror)` is the other legs **and their splines** as one model (the sweep and its path are mirrored together); dragging a dot of any leg's spline drags the original's point, changing the copies on the card redraws the legs; `Shift+S`, selecting the images brings back the mirror they were made in |
| `30_noise_kinds.py` | none (ten balls) | `noise_field`: the five kinds (`perlin`, `billow`, `ridged`, `cellular`, `cracks`), a stretch per axis, a `warp`, one octave against six, and a scale that is a field -- each ball is `ball - depth * noise`, so the relief is the noise |
| `31_texture.py` | none (twelve blocks) | `texture`: the six patterns (`grit`, `stipple`, `leather`, `ribs`, `dimples`, `knurl`), on the top face only (`select_surface`) or inside a body (`region`), `side='in'` / `'out'`, a pattern of your own, and a depth that is a field |
| `32_game_export.py` | none (a ball with a smaller one beside it) | exporting for a game engine: `export_mesh(..., units="cm")`, `up="y"` (a turn about X, not a mirror), `max_triangles=N` (the finest mesh within the budget), `symmetric="x"` / `"-x"` / `("y", 4)` (the half cut exactly at the plane and mirrored: symmetric to the last bit, closed); it writes the files, reads them back and prints `ok` / `FAIL` per check |
| `33_character.py` | none (a figure: spine, head, one arm of three points, a leg and a foot, mirrored) | a character from points: `chain([points], radii=[...])` makes a limb of round cones (`round_cone`) between the joints; the radius at a joint is its point's size -- the scale of its gizmo -- times `radii[i]`, so dragging the ring of the elbow thickens the arm there; blended into one body with `union_all(..., blend=4)`, the other half by `symmetric_x`; it prints `ok` / `FAIL` per check of the fields |
| `34_materials.py` | none (the figure of example 33) | materials and vertex colours for a game engine: `material(name, color, roughness, metallic, where=body or field)` -- layers, the last one that covers the middle of a triangle wins -- and `export_mesh(..., materials=[...], colors=(r, g, b))`: an OBJ with its `.mtl`, a GLB with a material and a primitive for each, a PLY with colours; it reads every file back and prints `ok` / `FAIL` per check |
| `35_uvs.py` | none (a box and the figure of example 33) | texture coordinates: `export_mesh(..., uvs="box")` -- each triangle projected along the axis its normal is mostly along, seen from outside, the vertices on a seam made again -- fitted (the texture once on each side) or `uvs=("box", 500)` (one repeat for every 500 mm, world-scaled), with `material(..., texture="skin.png")`; OBJ `vt`, PLY `s`/`t`, glTF `TEXCOORD_0`; it checks the areas in the texture against the areas in space, and prints `ok` / `FAIL` per check |
| `36_skeleton.py` | none (the figure of example 33) | a skeleton and skin weights for a game engine: `joint(name, position, parent, tip)`, `mirror_joints` (a `.L` joint for every `.R` one), `export_mesh(..., skeleton=bones)` -- a rigged GLB with the joints as nodes, the inverse bind matrices and for every vertex four joints and weights from the nearest bone, shared with the joint beside it near the ends of a bone (`skin_falloff`); it reads the GLB back and prints `ok` / `FAIL` per check |
| `37_pivot_and_lods.py` | none (the figure of example 33) | the origin of an asset and its levels of detail: `export_mesh(..., pivot="base" / "center" / (x, y, z))` -- the skeleton moves with it -- and `export_lods(part, "hero.glb", [8000, 2000, 500])` writing `hero_lod0.glb` to `hero_lod2.glb`, each within its budget of triangles; it reads the files back and prints `ok` / `FAIL` per check |
| `38_uv_maps.py` | none (the figure of example 33 and a crate) | UV maps: `uvs="box"`, `uv_planar("z")`, `uv_cylinder()`, `uv_sphere()` and `uvs="unwrap"` (`uv_unwrap(angle, margin, size)`: the surface cut into islands where it turns, each laid flat by a conformal map, scaled to one texel size and packed into the square), a second set for a lightmap (`uvs=[uv_unwrap(), uv_unwrap(margin=12)]`) and `uv_layout="layout.png"`, the picture of the islands; it checks the places against the square, the islands against each other and the size of a texel, and prints `ok` / `FAIL` per check |
| `39_baked_textures.py` | none (a rock) | textures baked from fields: `export_mesh(rock, "rock.glb", uvs="unwrap", materials=[...], textures=bake(size=256))` -- the colour (materials by region, a stone whose colour is a noise field, moss, gold in the cracks), the normal map (the exact normal of the field in the tangent space of the mesh) and the occlusion / roughness / metalness picture, as PNG files and inside the `.glb`; it reads the pictures back and checks them, and prints `ok` / `FAIL` per check |
| `40_armature.py` | none (a figure of limbs, a square limb and the bones) | an armature: `limb([nodes], radii=..., name=..., joints=[...])` (a round limb, or any 2D shape swept along the nodes with `profile=`), `character(limbs, blend, symmetric="x")`, `skeleton_of(limbs, mirror="x")`, a joint that owns a place of the skin (`influence=`) and up to eight joints a vertex (`max_influences`); it reads the rigged glTF back and prints `ok` / `FAIL` per check |

(Open each script: the comment at its top says what to look at.)
